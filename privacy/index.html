Personal Dashboard

Privacy Policy

Personal Dashboard is a private, single-user Obsidian plugin built and used by one person. It is not offered to anyone else and has no other users.

It reads the operator's own Google Calendar entries, and creates or updates entries in that same calendar, using credentials the operator supplies on their own machine. Calendar data is used only to display and edit that calendar inside the operator's local Obsidian vault.

No data is collected, stored on a server, shared, sold, or transmitted to any third party. There is no backend, no analytics and no tracking. All data stays on the operator's own devices. Access can be revoked at any time from Google Account permissions.
